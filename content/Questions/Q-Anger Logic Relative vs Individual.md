This was a question regarding how [[Gamma Cameras, Classical and Solid State#Electronics|Anger Logic]] functions given the low number of events that are actually occurring.

When [[Gamma Cameras, Classical and Solid State|Gamma Cameras]] perform Anger Logic to locate the actual event origin in a patient they are **not** necessarily locating an individual event.  While the [[Gamma Cameras, Classical and Solid State#Scintillation Crystal|Scintillation Crystal]] does cause multiple visible light photons to be released for a given gamma ray (assuming high enough conversion efficiency); this would still only provide a limited (e.g. 5) number of photons for gamma, which given the statistical randomness of where these events will land would not locate the event in space to any reasonable degree of precision.

This means that when looking at an image, we have not necessarily located an individual event location on the image, we know the number of events overall, as signals are quantised, and using this in combination with anger logic performed on the total signal to each of the [[Gamma Cameras, Classical and Solid State#Photo-multiplier Tube|PMTs]] allows for the counts to each area to be measured, despite the restrictions to an individual event.
